# 🪽 Pure Theme for Pterodactyl

**Pure Theme** is a clean, modern, and beautiful theme for the **Pterodactyl Panel**. It gives your panel a fresh and polished look while keeping the interface simple and easy to use.

## ✨ Features

* 🎨 Modern & clean UI
* ⚡ Smooth and lightweight design
* 🖥️ Designed for Pterodactyl Panel
* 📱 Responsive interface
* 🌙 Beautiful dark-themed experience
* 🔧 Easy to install and customize
* 💾 Automatic backup before installation

## 🚀 Installation

### Requirements

* Linux server
* Pterodactyl Panel
* Root/sudo access
* Git
* Node.js + npm or Yarn

### Quick Install

Run this command on your Pterodactyl server:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/linuxebug/Pure-Theme-Pterodactyl/main/install.sh)
```

Or install manually:

```bash
git clone https://github.com/linuxebug/Pure-Theme-Pterodactyl.git
cd Pure-Theme-Pterodactyl
sudo bash install.sh
```

The installer will:

1. Detect your Pterodactyl installation
2. Create a backup
3. Download the latest Pure Theme
4. Install the theme files
5. Rebuild the Pterodactyl frontend
6. Clear Pterodactyl/Laravel cache
7. Restart the required services

### 🔄 Update

To update to the latest version, run:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/linuxebug/Pure-Theme-Pterodactyl/main/install.sh)
```

Your existing files will be backed up before installation.
